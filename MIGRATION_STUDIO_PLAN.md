# Migration-only development roadmap

M1: authenticated job storage, ownership and secure connector credentials.
M2: website crawl, sitemap discovery, pages/assets/SEO inventory with coverage report.
M3: route, component and CMS field mapping with review gates.
M4: first adapter: static HTML -> Astro -> Cloudflare Pages staging.
M5: automated responsive screenshots, link checks, SEO checks and issue tracker.
M6: approvals, production publishing, version history and rollback.
M7: Webflow, Framer, WordPress and GitHub adapters subject to available API permissions.
M8: AI mapping and code-generation suggestions with confidence and human review.

Each phase requires build/typecheck, browser QA, and security validation before marking complete.
